# Minecraft Pocket Edition

The SF3000-compatible Minecraft PE core is based on
[Synaps33/FroggyPE](https://github.com/Synaps33/FroggyPE). The release provides
the core, runtime data, and launcher. The installed layout is:

```text
roms/ports/Minecraft PE.sh
roms/ports/mcpe/data/
```

Select **Minecraft PE** from **Games → Ports**. Use L2 to jump; R2 is
mapped to the secondary action.
