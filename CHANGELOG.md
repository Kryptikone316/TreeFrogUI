# Changelog

Permanent project history. Per-release announcements are kept separately in
[`release-notes.md`](release-notes.md).

## 2026-10-27

- **v1.8.0_t prerelease:** Added ScummVM based on [Synaps33's FroggyScummvm](https://github.com/Synaps33/FroggyScummvm); restored missing system artwork and translations; and reduced PicoArch audio popping under heavy load.
- **Ports Collection:** Ports are released separately from TreeFrogUI. Get the
  latest archive from the [Ports Collection releases](https://github.com/tzubertowski/TreeFrogUI_PortsCollection/releases/latest)
  or install them through the TreeFrogUI Installer's **Install ports** option.
  See the [Ports installation guide](docs/cores/ports.md).
