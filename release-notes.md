# TreeFrogUI v1.8.0_a prerelease

## What's new

- Added **OpenLara (Tomb Raider I)** to **Games → Ports**. Bring your own Tomb Raider game data; the [setup guide](docs/cores/openlara.md) lists the required files.

Thanks to [XProger and the OpenLara contributors](https://github.com/XProger/OpenLara) for the original project, and to [TreeFrogUI_OpenLara](https://github.com/tzubertowski/TreeFrogUI_OpenLara) for the SF3000 integration.

For a fresh installation, use the full archive and matching `install_first/<device>/` files. To update an existing installation, copy `update.zip` to the SD-card root and reboot. Back up your card first.
